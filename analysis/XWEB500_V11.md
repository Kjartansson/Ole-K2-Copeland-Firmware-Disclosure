# XWEB500 v1.1 (2007) recovery and security analysis

## Source and decoding

- Official package: `XWEB500v11.zip`, SHA-256
  `4be812090b8f1be2b9c989cd092c6d38d28edee7403eebab7d395431d0b6d3b7`.
- The ZIP is unencrypted and contains six `.xw5`/`.xwb` payloads plus two update
  manuals. Each payload decodes with single-byte XOR `0xa7` into a valid gzip
  stream. This is not the EVO `.epkg` format.
- `tools/xweb500_uf_extract.py` parses the decompressed `XWEB300UF` and
  `XWEB500UF` archives, including their newline-before-`EFI300IFE300!` framing.
- A total of 1,801 files was recovered: 6 + 11 + 876 + 853 + 34 + 21.
  ARM updater and application binaries, web pages, configuration, and the user
  database are present under `extracted/XWEB500_v11_files/`.

## Confirmed security findings

### Default administrator credential

`usr/xweb500/db/utenti/dbUser.db` contains `Admin|1161778906` and
`Admin|1161773656`. Those are MD5(`Admin`) and MD5(`admin`), matching the known
default `Admin`/`Admin` credential. This is independent of the later EVO
daily-password and pass-the-hash findings.

### Unauthenticated file write/delete

`usr/xweb500/cgi-bin/lo_utils.cgi` reads `ACTION=%d` from stdin and dispatches
values 0–5 directly to load, save, directory, delete, upload, and free handlers.
No authentication check occurs in `main`.

- `lo_image_upload` at `0x8bf8` constructs a path from
  `/usr/xweb500/db/Layout/images/` plus the supplied first input line, then calls
  `fopen` and writes request data. The filename is concatenated without a
  canonical-path or traversal check.
- `lo_del_image` at `0x8b6c` constructs the equivalent path and calls `unlink`.
- `cal_save.cgi` at `0x8e30` reads a filename and constructs
  `/usr/xweb500/db/cal/<input>`, then calls `fopen` and writes request data. No
  authentication check or traversal validation is visible.

These code paths match the mechanism later described by CVE-2021-45420. This is
therefore a known-vulnerability code verification, not a new zero-day claim.
No live write or delete operation was performed.

## Select 8.47.1 compatibility

`Select8.47.1_FULLDRAW.zip` is a separate Windows MSI installer. It contains no
XWEB firmware or compatible `.epkg` target; see `analysis/SELECT-8.47.1.md`.
